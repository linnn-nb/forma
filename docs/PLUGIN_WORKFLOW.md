# AU / VST3 插件使用

结论：开发应用可从原生插件库扫描、预览并插入真实 AU/VST3，可打开插件自身的真实窗口；公开参数由命令层捕获为人工事务，支持旁通、撤销及保存恢复。实际资格目前覆盖 macOS 的 AUNBandEQ 1.6.0 和 Serum 1.3.6.8；不是全插件兼容声明。

## 亲手试 AU

1. 启动 build-v2-tracktion/NativeDAW_artefacts/Release/NativeDAW.app，导入一段自己的音频，接受导入计划并选中轨道。
2. 视图 → 插件库 · AU / VST3。已验证的 AUNBandEQ 可直接选择；其他插件先“发现插件”，选择候选，再“扫描 / 重扫”。失败或黑名单项不能插入。
3. 选择 AUNBandEQ → 预览插入到目标轨道 → 接受计划。取消或过期预览不修改工程。
4. 右侧插入/参数中选中 AUNBandEQ，调实际 Global Gain，原生 ID 为0；归一化0.75对应本次实测的−6 dB。参数显示使用插件实际格式化文本，不能把所有0–1值当作dB。
5. 点击“插件窗口”打开 AU 自身编辑器。调 Global Gain 后停止播放，Undo/Redo 核对声音；窗口保持打开。再次点击或使用窗口关闭按钮关闭，移除插件和重开工程会释放旧窗口。
6. 播放/停止，试旁通，再 Undo/Redo。另存新工程并重开，核对插件、参数和音频。原始媒体保留。

## 亲手试 VST3 乐器

新增轨道类型选 MIDI（空 MIDI 轨），在插件库选择已扫描的 Serum，经预览确认插入。在钢琴卷帘写入音符，再播放。普通“乐器”轨默认已有 FourOsc，若使用此类型应明确移除 FourOsc，避免叠加两个音源。大型参数列表每页最多64个控件，上一页/下一页可访问所有实际枚举参数；不是削减可编辑参数数量。

本机 Serum 扫描返回2397个 SDK 参数，Tracktion仅开放317个可自动化参数，加上宿主 Dry/Wet 为319个命令参数。未公开或未枚举的内部状态不声称可控制。第三方插件自身许可证由用户持有，本程序不提供插件资产。

## 第三方自动化

在轨道右侧“自动化”页选择插件实际的实例ID::参数ID。Read可以添加/移动/删除真实曲线点；Touch/Latch/Write在播放中调插件原生窗口的公开参数，停止后产生一笔可撤销录写。Touch返回原曲线，Latch/Write保持到停止。当前实际声音资格覆盖 AUNBandEQ 的 Global Gain 和 Serum 的 MasterVol；第三方参数调度按实测块边界，不能据此推断所有参数都达到采样级。

## 失败与边界

扫描在独立进程中，有超时、取消、退出回收、黑名单和重扫；播放默认进程内，无固定1024帧IPC。进程内插件崩溃仍可能终止应用，播放沙箱/崩溃恢复未实现。缺失、黑名单或模块变更时保留工程引用与原始状态，活动缺失插件阻止播放/导出；用户明确旁通后可以继续。损坏插件目录不会阻止基础 DAW 启动，但显示真实诊断，原文件不被替换。

插件私有预设/非参数状态变化尚未形成独立人工事务，不公开的内部状态不声称理解或控制。插件侧链/多输出、参数动态重排、插件升级状态迁移、AUv3异步创建、真实监听往返延迟和长时间资格待验证。真实AU/VST3窗口创建、关闭、删除/Undo/重开和公开参数通知的实际PCM测试已执行；物理点击/设备试听因桌面锁定未执行。此功能不代表 M1 已完成，也没有 MCP 或真实模型端到端通过声明。

## Program 与故障恢复

选中已加载的 Serum，在插入/参数检查器中可看到实际 Program 索引（0起始）及 SDK 名称。停止播放，输入1，点“切换 Program”，再 Undo/Redo；可另存工程、重开核对。此版本 Serum 给 SDK 的名称是 prog 0 等，它们不能冒充 Serum 私有预设浏览器中的音色名称，切换索引也不保证音色不同。

如果插件自身的 Program 发生变化，L1在human历史记录原始状态，之前的编辑计划会失效。播放期间只显示“停止后捕获”，不读取blob。状态读取失败时检查器显示真实错误，提供“重试读取”和“还原已知状态”；后者明确丢弃无法捕获的未知变化，并记录不可撤销的人工历史；旧Undo不能穿过恢复，新操作仍可正常撤销。多个插件出错时，分别选择并恢复。正常状态不显示故障按钮。

本次自动化验证使用实际Serum实例/Program API及生产GUI组件回调，不能替代物理点击与试听。未发通知、同索引的私有预设变化和Programme自动化尚未获得实际资格。

## 切换设备格式后的参数与历史

按上述步骤插入 AUNBandEQ，将 Global Gain 设为 −6 dB（检查器实际归一化值 0.75），停止播放并关闭监听。在「音频设置」选择设备支持的 44.1 kHz/128 帧或 96 kHz/128 帧，等实际回执完成，再播放/导出、Undo/Redo 和另存重开。重配会关闭原生插件窗口；可以重新打开。设备配置本身不占工程 Undo，参数 Plan/人工手势仍能各自撤销。

JUCE 重建 AU 参数列表时读取原生值；频率等参数的归一化端点随设备速率变化，由 L1 识别并发布为准备状态。归一化自动化值遵循插件实际范围，不承诺跨采样率保持所有参数的绝对 Hz。真实 AU + Serum 双插件的数值/历史专项已通过；密集工程、动态参数重排、未知私有状态与硬件往返延迟仍未资格。
