# 录音就绪与输入失效

本增量统一 L1、GUI 和 Agent 的录音前置检查；缺失输入的原始引用和请求状态保留，用户仍能取消待命、关闭监听。就绪不等于录音成功，只有原生捕获和文件校验回执才报告结果。

实施前预算（2026-10-07）：48 kHz / 256 帧、两路已知 PCM、两条 audio 轨；正常录音保持现有 RMS 容差 3e-4 和同步差 ≤256 帧。停供测试输入后，500 ms 未见实际处理帧推进即判失败；20 Hz message-thread 检查，测试观测上限 1000 ms。该预算不保证阻塞的 GUI 线程仍能按时检查，不替代实时 deadline、实体拔插或耐久验收。专项测试上限 60 秒；不降低既有负载。

检查范围：音频设备 open/running、实际启用输入声道、所有待命轨的设备和 MIDI 录制能力、停止状态、配置/手势/自动化事务、Read 自动化及当前线性录音限制。目录可写和剩余空间在开始录音时真实检查，不能将静态 ready 字段当成磁盘或持续回调保证。

失效后停止录音，保留已产生的真实文件和可恢复片段；回执必须保持 failed，Undo 只撤回工程片段，不能删除原录音。重新恢复设备后，由用户明确重新录音，不自动续录。

状态：实现与测试进行中。物理麦克风、实际设备拔插和监听往返延迟待执行。
