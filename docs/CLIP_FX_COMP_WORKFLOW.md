# 带 Clip FX 的 Take／Comp（2026-10-15）

2026-10-15 更新：本页的处理窗口整体移动限制已由[PROCESSED_CLIP_MOVE.md](PROCESSED_CLIP_MOVE.md)的414项资格部分补齐；自由修剪/拆分/复制及复杂联动仍保留。

普通音频、SoundTouch 伸缩／独立变调、Warp 来源可带原生 EQ、压缩、延迟、混响创建 Comp。完整来源输入经过真实效果器，再按选段输出；切点不会把效果输入重新裁成互不相干的小片段。源码 `f83a269`，最终15套1722项/384.32秒全绿（含265专项/35.69秒），见 `evidence/P3/summary.md`；完整 P1/P3 和产品仍未验收。

## 使用

1. 在完整来源片段上，编辑菜单「片段效果」或 ⌘⌃⌥E 打开 Clip FX 检查器，插入效果、修改实际枚举参数。该快捷键可自定义。
2. 当前专项从完整来源插入四类原生效果，再处理 SoundTouch／Warp；反向插入顺序尚无本轮专项资格。继承 Comp 窗口重设伸缩／Warp 仍须回原来源操作。
3. Option+L 打开 Playlists / Comp，登记 Take，拖选来源并加入候选，试听、创建 Comp。候选不自动替换原播放或目标列表；用于播放后才切换。
4. Comp 每段保留独立、可编辑的真实插件实例和新 ID；检查器显示「CLIP FX / 来源效果选段」。参数修改只影响当前副本，不改原 Take。它不是烘焙音频。
5. ⌘⌃F 编辑来源句柄内的交叉淡化；⌘Z／⌘⇧Z 撤销重做，保存重开保留原事务。⌘⌥B 导出真实 WAV。准备、试听和停止沿用原 Playlist 控件及可改键入口。

本地测试结果 `build-v2-tracktion/p3-clipfx-comp-tests.json` 的 `cases[].session` 可直接打开三个真实工程；媒体和 WAV 留在忽略构建目录，没有上传或覆盖用户素材。退出旧进程再打开唯一新构建 `build-v2-tracktion/NativeDAW_artefacts/Release/Forma.app`。

## 信号与工程模型

L1 在实际切片时写入 `NDAW_CLIPFX_WINDOW` schema1：完整输入长度、原偏移锚、实际缓存输入偏移、媒体 SHA、Warp／Elastic 输入处理链和指纹。完整 Take 的普通复制不强加窗口，不截断原生尾音。媒体时间、完整处理输出时间、当前工程位置继续分开。

L0 的原生 WaveNode 读取完整来源，原生 Clip 插件处理后，来源包络和当前交叉淡化相乘，并在窗口外静音。带窗口的轨道复用 SummingNode 持续处理输入，避免 CombiningNode 在切点前跳过插件。构图读取发生在非实时阶段，没有新 DSP、引擎、服务、IPC 或在回调中分配窗口数据。

同一起始走带条件下，切点两侧保留原生效果状态。中间启动／跳转仍遵循原生引擎的初始化条件，不宣称重建任意长的历史尾音。每段副本各有真实处理器，密集切片的负载仍需测量；没有宣称性能或听感达标。

`clip_fx` 查询区分输入指纹、插件状态指纹、实际处理链指纹和输出窗口。规范化 XML 属性次序、无处理内容的空容器；四类锁定原生效果按 SDK 实际 float 参数计算，淡化／几何保留 double 精度。真实参数、顺序、来源处理、增益／声像及淡化变化都会改变相应指纹。未带效果和窗口的普通片段直接返回，不生成 XML。

GUI 仍只建 Plan；只有 L1 在 message thread 改 Edit，一项操作一笔 Undo。试听快照使用 ClipCopy 递归分配插件／片段新 ID，避免与活动图共享实例。媒体和描述失效时拒绝消费；坏工程打开失败保留当前会话。

## 验证与未完成

`ClipFxCompTests.cpp` 使用真实 PCM24 双声道、实际四插件串联、三种来源、native WAV 和 hosted 256 帧回调；验证切点／窗口静音／交叉淡化／真实参数改声／原 Take 和媒体 SHA／保存重开原 UndoRedo／坏输入拒绝／可改键注册。固定 PCM 容差 2e-6，来源准备5秒、单次 WAV10秒、专项180秒。最大PCM差1.1920928955078125e-7；窗口外输出0，六次hosted试听均非静音且零原生缓存miss。导出对照排除整体首尾256采样，选段内包含真实切点；hosted对照沿用原启动/结束窗口。没有用静音或假处理器作为成功音频。

最初重开失败的实际差异是原生 float 参数与 double 淡化字段的 XML 数值写法；失败和原生树对照保留，按实际精度修正语义指纹，同时规范化属性次序和无处理内容的空容器，没有放宽数值或时间预算。最终输出和受影响回归见 P3 证据。
