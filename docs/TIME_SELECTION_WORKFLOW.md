# 时间选区与定位

结论：本轮实现 M1 的工程时间选区、精确定位和选区 WAV；验证结果在执行后填入 VERIFICATION.md。不等于循环/Punch 或完整 M3 分析服务。

- 编辑 / 定位与时间选区，或顶部「定位 / 选区…」。按工程采样或秒输入，应用选区；一笔 human Plan 可 Undo/Redo。选区保存在 Edit 的 NATIVEDAW 元数据里，重开后仍在；小节/拍号变化不移动它。
- 区间采用 `[start,end)`，工程基准 48000 Hz。与音频设备实际采样率、文件 PCM 位深、插件精度分别说明。定位通过 L1 操作原生 Transport。
- 选区导出真实 Master（含其处理链），48 kHz / 24-bit / 双声道 WAV。按指定帧数核验并测量 Peak/RMS/LUFS-I/True Peak；范围外尾音不自动增加。常规导出按钮仍导出完整工程。
- 文件对话框绑定 session_token、revision、范围；任何人工编辑、切换工程或范围变化都会使旧请求失败，不能静默改用新状态。不得覆盖现有路径；没有成功文件回执不显示导出完成。
- Agent 查询 `time_selection`，由注册表自动产生 `plan.session.range.set/clear` 工具。范围修改属于全局操作，限 unrestricted preview + GUI 确认；现有指定轨道自动权限不能扩大成全工程。

实现前固定验收：M1-RANGE-01，2 秒 48 kHz 双声道已知信号，非零起点 24000 到 72000；另测不落块边界的 24013 到 71971。真实渲染每次 <10 秒，总测试 60 秒；帧数精确、PCM 数值对照容差 2e-5。覆盖有序 Plan 预览、Undo/Redo、重开、Tempo 后范围、过期与跨工程请求、权限/整数/越界、文件冲突及生产界面回调。桌面文件导出单独验收。

边界：导出当前仍走既有同步 SDK renderer，有取消/响应性改造待后续；本轮不承诺大型工程吞吐。选区可越过最后片段供尾音范围指定；不自动侦测尾音。持久 Undo 尚未实现。
