# 原生旁链（2026-10-14）

内置 Compressor 的旁链音频与保存历史已验证；第三方旁链、硬件PDC、mute/solo和听感仍待测。这是 P2 第一个功能，完整 P2 未完成。

选择接收轨的 Compressor，在检查器「旁链…」选择另一条音频/Aux/乐器轨，Cmd Return 连接。默认入口 Cmd Option S，可改键；示例工程保存了 Ctrl Option Q。选择「无」断开，Esc 取消，Cmd Z / Shift Cmd Z 撤销重做。未改变来源时 Apply 禁用，不产生历史。保存副本后重开，原事务和键位保持。

主输出不变；触发轨可输出 None，仍供检测。直接来源为原生轨道插件/推子后信号，已测推子影响；需要 PRE 信号时先建立 PRE send→Aux，再选 Aux。自定义针脚映射UI、任意多声道格式和该PRE组合的数值验收尚未完成。支持入口严格使用已载入实例的实际输入布局；外部插件的私有检测器开关不猜测，需其真实参数/窗口设置。内置压缩器自动设置实际 `sidechainTrigger`；它的3输入原生默认将触发L+R相加，没有隐式归一化。

统一命令 `plugin.sidechain.set` 是 human/local_gui、停止态、独立事务。预览列出源/针脚/检测器前后状态；实时图/PDC由Tracktion处理，不引入IPC。源引用依稳定ID，失效保留；缺失源阻止录放/导出，不假报成功。自反馈及输出/发送/旁链合成循环拒绝，损坏工程加载不能替换当前工程。删除触发源默认拒绝，显式disconnect预览列出所有移除的旁链，同一Undo恢复源与检测器。
