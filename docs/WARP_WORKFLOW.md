# Warp 锚点工作流（2026-10-14）

已接通原生 SoundTouch 非线性离线处理、L1 事务与真实波形编辑器；当前资格与未完成项以 `evidence/P3/summary.md` 为准。不是完整 P3、听感或发布验收。

选择音频片段，编辑菜单「Warp锚点 · SoundTouch…」或 ⌘⌃⌥W（可改键）。双击下方波形或「添加中点」建立草稿锚点，拖动改变片段内位置；左右键微移10ms，Option左右键微移1采样，Delete移除中间点。也可选锚点输入源秒与目标毫秒。首尾源位置固定，首输出点为0，尾点可改时长。⌘Return 提交，Esc丢弃草稿；一笔工程Undo恢复所有锚点，保存重开保持原历史。「还原Warp前状态」恢复原生时长、偏移、速度和音高，它本身也可撤销。

源位置为原媒体绝对秒，目标为片段内48k工程采样；不是原文件PCM帧号。前后未选源区间保留恒等映射，时间线起点保持。处理算法与许可沿用锁定 Tracktion 内 SoundTouch 2.1pre / LGPL-2.1-or-later，不新增依赖。原媒体不覆写；32-bit float中间缓存与交付PCM24分别处理。界面波形是按锚点映射的真实原媒体缩略图，不声称等同处理后频谱或听评。

`clip.warp {clip,enabled,anchors:[{id,source_time_seconds,clip_time_samples}],media_hash}` 只经L1、停止态、human/local_gui、单操作Plan；不扩冻结MCP权限。源SHA256、源区间、原几何和处理链SHA256存于同一原生Clip树，原生WARPMARKER持稳定ID。版本、对象、重复ID、递增位置、源范围、每段0.5–2倍和2–128锚点在预览/提交校验；失效Plan拒绝，重试幂等。Warp设置提交与音频准备完成分别回执；缓存准备中、失败或原媒体改变时拒绝录放/导出。

离线印刻、Stems与Master分析仍使用同一Engine的临时原生Edit；L1绑定已准备好的Warp源缓存，原引用及原生音高处理保留，缓存列入渲染前后文件哈希核验。SDK forRendering 的 shouldPlay=false 会跳过自身Warp源渲染，不能直接按普通原文件处理。播放实例不接受此离线绑定。失败或取消不复制原音频冒充完成；Undo退出Warp时取消源任务；再次应用重建与工程树绑定的原生管理器。

已用实际WAV验证48k/44.1k非零源偏移、两段不同伸缩比与440/880Hz保音高、PCM/声道关系、保存重开/原UndoRedo/重新应用、源改变、真实OS写盘限制、印刻/Stems/Master消费。短缓存准备5秒、单次render/印刻/分析10秒、Stems20秒、套件120秒；音高1Hz、频率转换窗口50ms、立体声2e-7、印刻/Stems2e-6预算预设后保持。结果见P3证据；不是硬件延迟、长素材或随机插件逐位一致性证明。
