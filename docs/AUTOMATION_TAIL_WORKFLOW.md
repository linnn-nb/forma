# 跨轨自动化尾随

跨轨移动可以带上明确长度的自动化后续区间，避免在片段结束时立即恢复目标参数而切断效果器尾音。这是可调整的制作范围，不是自动尾音检测，也不保证任意插件的声音完全相同。

## 亲手操作

1. 停止播放，在编辑菜单「跨轨自动化尾随」选择仅片段、0.5秒、2秒或5秒。默认2秒。默认快捷键为 Command Control Option Shift 加 `0`、`1`、`2`、`5`，可在快捷键设置改键。
2. 开启「自动化跟随编辑」，按 F8，把带自动化的片段拖到有对应插件和参数的目标轨道，也可用既有上下轨快捷键。
3. 预览逐参数显示尾随秒数及实际结束位置。接受后一次 Command Z 撤销，Shift Command Z 重做；设置本身也有独立 Undo，随工程和原历史保存。
4. 播放或导出完整范围，检查尾音。需要改变长度时先取消预览，再改设置、重新移动。选择仅片段会明确回到片段末恢复参数的行为。

只有处理链含推子以外插件、且来源有实际曲线需要迁移时，才保守增加尾随区。仅推子链不增加范围；关闭自动化跟随时不迁移曲线。这一设置用于跨轨 `clips.relocate`，不改变同轨移动、复制和 Shuffle 的既有范围语义。

## 实际工程规则

- 片段内点保留身份并迁移；后续区间复制源曲线，使用新点 ID、保留未知原生属性，并记录 `ndaw_copied_from`。来源片段外的原点保留，不被尾随复制搬走。
- 目标匹配参数在片段及尾随区间内被替换，预览包含实际前后点；范围结束后恢复目标曲线。用户已有的目标尾随区自动化会被替换，接受前须核对范围。
- 源或目标尾随区遇到未移动片段时整笔拒绝。同批其它移动片段的最终位置也检查，不能用没有源自动化的片段绕过。多个来源占用同一目标参数的重叠区同样拒绝。
- 只用真实参数 ID、插件槽位/身份和原生范围，不猜测第三方内部状态。实际源曲线先冻结，再统一写入一个原生 UndoManager 事务；幂等、版本冲突、锁定及双侧 Scope 保持。涉及自动化迁移仍需完整时间授权。
- 工程采样单位48k。设置表示源时间上的后续长度；音乐时钟按既有拍映射，目标秒数可能不同，以实际预览为准。

L1 `session.relocation_tail.set {samples}`，本地 human、停止态、独立 Plan，整数0–1440000。`NATIVEDAW/RELOCATION_OPTIONS` schema1存储 `tail_samples`；缺省96000。旧 `EDIT_OPTIONS` schema1及跟随开关不改。打开时校验重复节点、字段、schema和范围；查询在 `editing_options.relocation_tail_samples` 返回实际设置。

## 验证与限制

编号 `P3-RELOCATION-TAIL-01`。代码：`RelocationAutomation.cpp`、`TimelineCommands.cpp`、`EngineCommands.cpp` 和 `ui/WorkspaceGrabber.cpp`、`WorkspaceCommands.cpp`、`WorkspaceLayout.cpp`。

`RelocationAutomationTests.cpp` 使用真实 Volume/Pan/EQ、原生曲线求值、来源与目标已有点、未知属性、两侧及同批到达冲突、全局设置 Scope、人工冲突、原 Undo 和三份冷重开工程；真实 PCM24/48k 双声道 WAV 沿用原2e-6门槛、5秒来源准备、10秒每次渲染和180秒套件预算。尾随范围内按源曲线检查，范围外检查目标原曲线恢复，不把范围内点继续当“必须保持原值”的外部点。

`RelocationTests.cpp` 通过真实 Workspace 注册快捷键设置0.5秒，保存后冷重开原 Undo/Redo，再用 live Undo 恢复2秒；组件事件不代表实体键鼠。当前测试终态、实际 PCM 和工程入口见 [P3证据](../evidence/P3/summary.md)。

更长的混响/Delay/虚拟乐器释放、之前音频留下的状态、共享路由及第三方插件仍需按实际信号验证。选择的尾随长度过短仍可能改变剩余尾音；GUI不依据工程提交回执宣称声音验证成功。关联多轨 Comp、复杂 Tempo/子采样端点/采样率、实体听评、原性能和发行差距继续保留，完整 P1/P3 与产品未完成。
